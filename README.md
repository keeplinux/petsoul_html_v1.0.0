## 目录说明

- `static/` — 静态站点资源（首页、样式、字体、图片）
- `docs/` — 站点文档与发布配置（含 GitHub Pages 部署文件）
- `deployment/` — 服务器部署配置（Nginx、systemd、部署脚本）
- `docs/deployment/` — 部署操作手册与验收说明
- `design-proposal/` — 设计提案与样式预览
