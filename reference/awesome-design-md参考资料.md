## 项目简介

**Awesome DESIGN.md** 是一个精选集合，收录了 73 个知名品牌网站的 **DESIGN.md** 设计系统文件。每个文件通过深度分析真实品牌的视觉语言生成，包含色彩令牌、排版层级、组件样式、布局规则、阴影系统等完整的设计深度。

核心理念：将视觉设计转化为 AI 可以直接理解的纯文本，让 AI 编码智能体生成视觉一致的高质量 UI。

---

## 对 Petsoul 官网的帮助

### 1. 建立 Petsoul 自己的 DESIGN.md

可以参照该仓库中顶级品牌的设计系统写法，为 Petsoul 官网编写一份 `DESIGN.md`。之后任何 AI 开发工具都能直接读取，确保后续所有页面、所有模块保持视觉一致性。

尤其适合 Petsoul 当前"纯前端无框架"的技术路线——没有组件库约束，更需要一份文本化的设计规范来约束 UI 一致性。

### 2. 借鉴同类品牌的设计思路

仓库中有多个品牌与 Petsoul 的"温暖 + 科技 + 情感"调性接近，值得重点研究：

| 品牌 | 为何值得参考 |
|------|------------|
| **Airbnb** | 温暖的色调系统、情感化设计、社区感 |
| **Stripe** | 干净的现代 UI、微交互、渐变运用 |
| **Apple** | 极致的细节、写实质感、动效节奏 |
| **Nike** | 强烈的品牌识别、大视觉冲击 |
| **Linear** | 现代工具型产品的精致设计 |

### 3. 设计约束与护栏

每个 DESIGN.md 包含"设计反模式"章节，明确列出什么不能做。这对 AI 生成代码时避免常见 UI 踩坑非常有价值。

### 4. 响应式设计参考

每个文件包含断点策略、触摸目标、折叠行为等移动端规范，可对照 Petsoul 的移动端优先策略进行优化。

## DESIGN.md 文件结构（标准章节）

| 章节 | 内容 |
|------|------|
| 视觉主题与氛围 | 情绪基调、设计密度、设计哲学 |
| 色彩调色板与角色 | 语义化颜色 + 十六进制码 + 功能角色 |
| 排版规则 | 字体族、完整层级表 |
| 组件样式 | 按钮、卡片、输入框、导航栏及其状态 |
| 布局原则 | 间距刻度、网格系统、留白哲学 |
| 深度与层级 | 阴影系统、表面层级 |
| 设计规范 | 设计护栏与反模式 |
| 响应式行为 | 断点、触摸目标、折叠策略 |
| 智能体提示指南 | 快速颜色参考、即用型提示词 |

## 与 AGENTS.md 的协同

| 文件 | 读者 | 定义什么 |
|------|------|----------|
| AGENTS.md | 编码智能体 | **如何构建**项目 |
| DESIGN.md | 设计智能体 | 项目**长什么样** |

两件套搭配使用，AI 就能同时理解项目的技术规范与视觉规范。
