# AI 官网设计参考资料：Leonxlnx/taste-skill

## 资料来源

- GitHub 仓库：https://github.com/Leonxlnx/taste-skill
- 收录日期：2026-07-06

## 资料定位

`Leonxlnx/taste-skill` 是一组面向 AI 编程工具的前端审美与设计执行规则。它不是 Petsoul 官网模板，也不是 Rust 网站框架；更适合作为官网视觉设计、页面布局、品牌表达和 AI 生成设计稿时的参考约束。

## 对 Petsoul 官网的帮助

- 约束 AI 生成官网时避免模板化页面、空泛营销话术和常见的同质化科技风。
- 帮助建立更清晰的页面设计流程：先确定品牌气质、页面目标、内容层级和参考风格，再进入代码实现。
- 可用于生成或评审首页、产品页、移动端页面、品牌视觉板等设计参考。
- 适合辅助 Petsoul 官网形成温和、可信、智能、生活化的视觉方向。
- 可作为后续检查官网设计质量的参考清单。

## 使用边界

- 本项目仍必须以 Rust 作为核心开发语言。
- 该仓库中的 React、Next.js、Tailwind、Motion 等相关建议只能作为设计实现参考，不能替代本项目的 Rust 技术约束。
- 不直接照搬外部仓库内容、代码结构或默认技术栈。
- 使用该资料时，应结合 Petsoul 的真实产品资料、品牌素材、用户场景和云端部署要求。

## 建议工作流

1. 先根据 `网页设计总纲.md` 明确页面目标、受众和内容结构。
2. 参考 `taste-skill` 的审美规则，生成或筛选官网视觉参考。
3. 将选定的视觉方向沉淀为 Petsoul 自己的页面规范、组件风格和文案原则。
4. 再使用 Rust 技术栈实现页面和服务端结构。
5. 开发完成后，用该资料的审美原则检查页面是否存在模板化、信息层级混乱、移动端体验不足等问题。

## 后续可提炼为 Petsoul 规则的方向

- 首页首屏必须直接展示品牌、产品和核心价值。
- 页面视觉应优先服务真实产品和真实使用场景。
- 移动端排版、按钮尺寸、图片裁切和文案长度需要优先验证。
- 避免过度依赖紫蓝渐变、玻璃拟态、大面积卡片堆叠等常见 AI 生成风格。
- 所有设计参考最终都要落回 Petsoul 的品牌气质和产品可信度。
