# Petsoul 官网设计方案 v2（详细版）

> 设计语言：**温暖之光** —— 科技是外壳，温暖是内核，用"光"而不是"金属"来表现科技。
> 配套样式图：打开 `design-proposal/style-mockup.html` 查看可交互的视觉演示。
> 本文档是"方案"，不涉及代码改动；落地路径见文末第 8 节。

---

## 1. 设计理念

### 1.1 一句话概念

> 把"硅宠场域"从冷科幻调成**暖科幻**：深空背景保留，霓虹换暖金，满屏加宠物，文案做减法，动效留一个签名。

### 1.2 五个关键词如何同时成立

| 关键词 | 解法 |
|--------|------|
| **简约** | 大面积留白 + 全场只有 1 个主强调色 + 一次只亮一个动效 |
| **大气** | 大字号明体标题 + 深色大画幅背景 + 1200px 留白节奏 |
| **科技感** | 数据用"光"可视化、3D 产品旋转、克制的几何参数字体 |
| **温馨** | 真实宠物影像、暖金调色、明体字、圆角与柔光 |
| **宠物** | 宠物不是贴图，而是贯穿版式、文案、数据可视化的系统元素 |

### 1.3 品牌叙事（保留现有世界观，改情绪温度）

- 保留：硅基探针 / 恒星观测 / 数字孪生 / 星尘归航 的意象框架。
- 改法：文案密度减半，每段只讲一件事；把"维度降临"这类宏大词替换为"它今天喝了 12 次水"这类**具体而有光**的表达。
- 叙事顺序：**产品（看得见）→ 数据（信得过）→ 孪生（记得住）→ 归航（放得下）**。

## 2. 视觉系统（完整 Token）

### 2.1 色彩

**深色模式（主推，首屏/产品/孪生区）**

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#1A1512` | 页面背景（暖相深色，拒绝冷蓝黑） |
| `--surface` | `#27201A` | 卡片/浮层表面 |
| `--line` | `rgba(255,255,255,.09)` | 描边 |
| `--text` | `#F7EDE3` | 主文字（暖白） |
| `--muted` | `#B8A89A` | 次级文字 |
| `--peach` | `#F0A06C` | **主强调**（体温/健康/生命力） |
| `--peach-deep` | `#E0894F` | 主强调 hover/深色 |
| `--sage` | `#7FB5A0` | 次强调（科技/洁净/水） |

**浅色模式（场景/信任/阅读区）**

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#FAF7F2` | 暖白背景 |
| `--surface` | `#FFFDF9` | 卡片表面 |
| `--text` | `#3A2E27` | 深棕主文字 |
| `--muted` | `#7A6B5F` | 次级文字 |

**严格禁止**：霓虹粉 `#ff5ea8`、霓虹青 `#66f0dc` 一律删除（它们是"夜店感"来源）。

### 2.2 字体

| 角色 | 字体栈 | 用途 |
|------|--------|------|
| 标题 | 宋体/思源宋体 `serif` | 大标题、区块标题（人文温馨大气） |
| 正文 | PingFang SC / 系统无衬线 `sans-serif` | 正文、说明 |
| 参数 | Space Grotesk / Questrial 几何字体 | 数字、参数、`tabular-nums` |

字号阶梯（rem，移动端优先）：`display 3.5` / `h1 2.25` / `h2 1.75` / `h3 1.25` / `body 1` / `caption .875`。

### 2.3 圆角 / 阴影 / 光效

- 圆角：卡片 `20px`，小控件 `12px`（柔和不幼稚）。
- 阴影：深色下用大范围低透明度暖阴影 `0 24px 60px rgba(0,0,0,.35)`。
- 光效：一律径向渐变 + `box-shadow` 辉光（`glow`），不用描边霓虹。产品底光为蜜桃色。

## 4. 组件规格

### 4.1 按钮

- **主按钮** `btn-primary`：蜜桃金渐变底 `linear-gradient(135deg,#F6C39B,#E0894F)`，深色文字，hover 上浮 + 暖光投影。
- **次按钮** `btn-secondary`：透明底 + 1px 描边，hover 底变 `rgba(255,255,255,.06)`。
- **文字链** `text-link`：暖金下划线，hover 微光。

### 4.2 产品参数卡

`strong`(几何字体大字) + `span`(说明)，例如 `8°C 冷星水温 / 45°C 暖洋恒温 / 6L 水星球储量`。数字用 `tabular-nums` 等宽对齐。

### 4.3 产品卡

- 布局：产品抠图置于 `160px` 直径蜜桃光晕（`radial-gradient`）之上，光晕缓慢呼吸（签名动效之一）。
- hover：卡片 3D 微倾（`transform: perspective() rotateX/Y`）+ 光晕增强。
- 宠物元素：卡片一角猫耳形高光，或副标题用宠物口吻。

### 4.4 数据可视化「呼吸光点轨道」

- 结构：中心宠物剪影/头像（柔光圆底，呼吸动画）＋ 外圈虚线轨道 ＋ 8 枚暖金光点沿轨道缓慢旋转、各自脉动。
- 语义：光点密集/更亮 = 该时段活动更高（饮水/进食/活动）。
- 技术：纯 CSS `@keyframes spin + breathe`（GPU 加速，无 JS）。

### 4.5 隐私与信任区块（新增）

三列：**你授权**（透明开关 UI）/ **加密存储**（传输+静态加密图标）/ **随时控制**（查看/导出/删除）。视觉用暖青强调色 `sage` + 简短文字，不制造压迫感。

## 5. 动效规格

| 动效 | 触发 | 时长 | 说明 |
|------|------|------|------|
| 暖光呼吸 | 页面加载 | 2.4s×3 | 全场签名动效，产品/宠物光晕一次呼吸 |
| 滚动淡入 | IntersectionObserver | .6s ease-out | 现有 `data-animate` 机制保留 |
| 卡片微倾 | hover | .35s | `perspective` 3D 微倾 + 光影跟随 |
| 光点轨道 | 进入视口 | 持续 32s | 数据区签名动画 |
| 慢视差 | 滚动 | — | Hero 背景 `transform: translateY` 0.3 速率 |

**砍掉**：Canvas 墨迹擦除遮罩、霓虹文字 SVG 循环。前者弱化为 logo 加载淡入，后者删除。

**性能**：全部使用 `transform/opacity` + `requestAnimationFrame`；移动端自动降级（`prefers-reduced-motion` 关闭呼吸与轨道）。

## 8. 查看样式图的方法

- **本机直接看**：用浏览器打开 `design-proposal/style-mockup.html`。
- **VSCode 内预览**：
  1. 安装扩展 **Live Preview**（微软官方，`ms-vscode.live-server`）；
  2. 打开 `style-mockup.html`，点编辑器右上角 **预览图标**（显示器+放大镜），即可在右侧面板实时同步预览；
  3. 或命令面板 `> Live Preview: Show Preview (Internal Browser)`；
  4. 想用真实浏览器并自动刷新：装 **Live Server**（`ritwickdey.LiveServer`），右键 HTML → `Open with Live Server`。
- 同步方式：Live Preview 在每次保存文件后自动刷新预览（保存快捷键 `⌘S`）。
